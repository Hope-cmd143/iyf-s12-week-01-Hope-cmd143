## 📂 Project Structure & Files

### Portfolio Core Pages
* **`index.html`** - Homepage introducing my portfolio and navigation.
* **`about.html`** - About Me page detailing my background and goals.
* **`projects.html`** - Showcase page displaying my foundation projects.
* **`contact.html`** - Fully accessible contact form featuring explicit labels, fieldsets, and validation attributes.
* **`semantic-conversion.html`** - A demonstration of converting unstructured code into clean, semantic elements (`<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, `<footer>`).

### Reports & Documentation
* **`devtools-exploration.md`** - Notes and findings from exploring browser Developer Tools.
* **`accessibility-report.md`** - Evaluation report highlighting web accessibility practices implemented.

### Daily Challenges (`/challenges`)
* **`challenges/day-1.html`** - Practice webpage utilizing 5 distinct HTML tags.
* **`challenges/day-2.html`** - Custom semantic navigation menu challenge.
* **`challenges/day-5.html`** - Structured blog post layout challenge.
