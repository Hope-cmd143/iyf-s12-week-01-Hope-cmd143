# DevTools Exploration Report

## Overview
During this exercise, I used browser Developer Tools (Chrome DevTools) to inspect live websites, examine the DOM structure, test styles in real time, and check for errors.

## Key Findings & Observations
1. **Element Inspection:** Using the Elements tab allowed me to see how HTML elements map directly to the rendered page and understand box model properties (margins, borders, padding).
2. **Console Debugging:** The Console tab is essential for identifying JavaScript errors, warnings, and logging runtime data.
3. **Responsive Design Mode:** Device toolbar emulation helped test how layouts adapt across mobile, tablet, and desktop viewports.

## Lessons Learned
Exploring DevTools provided a much clearer picture of how browsers interpret HTML and CSS, making it easier to debug layout issues quickly.
